# 使用说明

## Windows 电脑

1. 安装并启动“跨端快传”。
2. 电脑和 Android 手机连接同一 Wi-Fi。
3. 在 Windows 界面查看局域网地址，例如 `http://192.168.1.20:3210`。
4. 在手机 APK 的“手机连接电脑地址”输入此地址并点击“连接”。
5. Windows“发送到手机”添加的文件会显示在手机共享列表；手机选择文件后可发送到电脑。

## 文件保存位置

Windows 收到的文件保存在“文档/跨端快传/收到的文件”；电脑分享给手机的文件暂存在“文档/跨端快传/发送到手机”。

## 注意事项

- 当前版本只针对同一局域网使用，不通过云端中转。
- Windows 首次启动如弹出防火墙提示，请允许其在专用网络通信。
- 只在可信任的私人 Wi-Fi 中运行。当前 MVP 尚未实现连接口令和传输加密，不建议在公共网络中使用。
- GitHub Actions 输出的 Android APK 为 debug 签名测试包；正式发布应使用妥善保管的私有 keystore 签名。
